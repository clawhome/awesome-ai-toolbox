## 关于本仓库

本仓库是 [topxai.cn](https://topxai.cn) 的开源镜像，把站内收录的 AI 工具整理成一份可以直接阅读、也可以被程序消费的清单。

- **中文优先**：默认中文内容，同时提供 [English](./README.en.md) 版本。
- **自动同步**：每天由 GitHub Actions 从站点接口拉取最新数据并重新生成本文件，无需人工维护。
- **结构化数据**：除本文件外，`data/` 目录提供 JSON 与 CSV 两种格式，可直接用于自己的项目。

## 数据文件

| 文件 | 说明 |
| --- | --- |
| [`data/tools.json`](./data/tools.json) | 全部工具的结构化数据（含中英名称与描述、类目、标签、官方链接） |
| [`data/categories.json`](./data/categories.json) | 类目定义与分类分组 |
| [`data/tools.csv`](./data/tools.csv) | 同一份数据的表格版，方便用 Excel 打开 |
