## About

This repository is the open mirror of [topxai.cn](https://topxai.cn), turning the AI tools catalogued on the site into a list that is readable by humans and consumable by programs.

- **Chinese-first**: the [简体中文](./README.md) version is the default.
- **Auto-synced**: a GitHub Action pulls fresh data from the site API every day and regenerates this file.
- **Structured data**: the `data/` folder ships the same content as JSON and CSV.

## Data files

| File | Description |
| --- | --- |
| [`data/tools.json`](./data/tools.json) | Structured data for every tool (bilingual name & description, category, tags, official URL) |
| [`data/categories.json`](./data/categories.json) | Category definitions and grouping |
| [`data/tools.csv`](./data/tools.csv) | The same data as a spreadsheet, easy to open in Excel |
